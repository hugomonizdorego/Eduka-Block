EDUKA-BLOCK ACCOUNT DIRECTORY
=============================

After first setup, credentials.txt is created in this directory.
It is a normal UTF-8 text file and can be opened with Xed, Pluma, Gedit,
Mousepad, or another text editor.

For safety, the original password is NOT stored. The file contains a salted
PBKDF2-SHA256 password hash. It is owned by root and normal users cannot edit it.
Use the Eduka-Block menu to replace the parent/teacher account.
